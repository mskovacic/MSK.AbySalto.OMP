# Abysalto tehnički zadatak
## Online maloprodajna platforma

### Preduvjeti za pokretanje rješenja

- Docker
- .NET 10
- Nodejs (v25 lts)


### Preduvjeti za development

- dotnet tools - ef, kiota, aspire

### Pokretanje

- pokrenuti Docker
- pokrenuti osnovni projekt - u AppHost folderu  `dotnet run`


### Stanice

- AppHost - orkestrator za pregled stanja servisa
- frontend - za stranicu webshopa
- API
- Scalar - UI sučelje za API
